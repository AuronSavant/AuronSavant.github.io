# Auron's corner

A static, draggable scrapbook portfolio for AuronSavant. Open `index.html`, or serve this directory with any static HTTP server. No build or installation is required.

Drag to pan, scroll or pinch to zoom, and use the section navigation to jump around. The project index provides a searchable, keyboard-friendly alternative. Arrow keys pan when the canvas is focused; + and - zoom; Home returns to the introduction.

Project names, descriptions, links, and illustrations are in `app.js`. Personal copy is in `index.html`, and styles are in `style.css`. The three supplied character images are in `assets/`. Typography uses Google Fonts with local font fallbacks.

Published Cloudflare projects link directly to their apps. Private projects link to the GitHub profile. Excluded: YouTube3Blue1BrownishVideo, PolyScores, AIBusiness, GermanyGraduatePrograms, GitHub Committer, and PatternFinder. Generic GitHub training repositories are omitted.

## GitHub Pages

Publish this directory to `AuronSavant/AuronSavant.github.io`, then enable Pages from the main branch, root directory. The portfolio lives at https://auronsavant.github.io. Publishing these portfolio assets does not publish the private project repositories.
